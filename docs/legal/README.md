# Юридические документы «Клуба Партнёров»

Черновики для ООО СЗ «Хорошо». Перед подачей и подписанием их проверяет юрист: здесь описано, что приложение делает на самом деле, но решение принимает оператор.

| Документ | Где | Статус |
|---|---|---|
| Политика обработки ПДн | `/legal/privacy-policy.html`, текст в `server/privacyPolicy.js` | опубликована |
| Согласие на рекламные сообщения | `/legal/marketing-consent.html`, `server/legalPages.js` | публикуется с выкаткой |
| Правила акции «Призы за сделки» | `/legal/prize-rules.html`, `server/legalPages.js` | публикуется с выкаткой, нужна проверка юриста |
| Условия участия в клубе | `/legal/terms.html`, `server/legalPages.js` | публикуется с выкаткой, нужна проверка юриста |
| Уведомление в Роскомнадзор | [rkn-notification.md](rkn-notification.md) | черновик, подаёт оператор |
| Приказ об ответственном за ПДн | [order-responsible.md](order-responsible.md) | черновик, подписывает гендиректор |

Реквизиты на страницах берутся из переменных окружения `PD_OPERATOR_*` и `PD_CONTACT_*` в Amvera. Пока они не заданы, страницы отвечают «Документ готовится».

## Что осталось сделать оператору
1. Подать уведомление в Роскомнадзор (pd.rkn.gov.ru, раздел «Уведомление об обработке ПДн»). Обработку можно продолжать, но работать без уведомления — нарушение ст. 22 152-ФЗ.
2. Подписать приказ о назначении ответственного за организацию обработки ПДн и вписать его контакт в `PD_CONTACT_EMAIL` / `PD_CONTACT_PHONE`, если он другой.
3. Согласовать с бухгалтером НДФЛ с призов: стоимость призов сверх 4 000 ₽ в год — доход партнёра (п. 28 ст. 217 НК РФ). Если организатор удерживает налог как налоговый агент, это нужно отразить в правилах акции.
4. Показать юристу правила акции и условия участия; после правок поменять дату редакции через `PD_POLICY_DATE`.

## Аварийные выключатели
- `ENABLE_DOCUMENT_UPLOAD=false` — остановить приём паспортов и документов.
- `ENABLE_MARKETING_BROADCASTS=false` — остановить рассылку новостей и приглашений. Даже включённая, она уходит только тем, кто отдельно согласился на рекламу.
- `PRIVACY_CLEANUP_ENABLED=true` — включить удаление брошенных входов (по умолчанию только считает и пишет в лог).
