# Морские титаны: Разлом

Личная фанатская RTS по мотивам Submarine Titans. ТЗ: [GAME_SPEC.md](GAME_SPEC.md), архитектура: [ARCHITECTURE.md](ARCHITECTURE.md).

## Запуск

```bash
cd sea-titans
npm install
npm run dev        # http://localhost:5180
npm test           # тесты логики (Vitest)
npm run build      # проверка типов + сборка
```

Параметры URL для проверки:
- `?seed=7`: сид тестовой карты;
- `?map=256`: размер карты (по умолчанию 128);
- `?units=300`: сколько своих юнитов на старте.

Пример стресс-теста: `http://localhost:5180/?map=256&units=300`.

## Управление (этап 1)

| Действие | Клавиши |
|---|---|
| Выбор | ЛКМ, рамка; Shift добавляет; двойной клик выбирает всех такого типа на экране |
| Движение | ПКМ; Shift ставит в очередь |
| Атака-движение / патруль | F / P, затем ЛКМ (боя пока нет, атака-движение ведёт себя как движение) |
| Стоп / держать позицию | X / H |
| Группы | Ctrl+1..9 назначить, 1..9 выбрать, двойное нажатие наводит камеру |
| Камера | WASD, стрелки, края экрана, СКМ — тащить, колесо — зум, клик по миникарте |
| Время | Пробел / Pause — пауза, + / − — скорость 0.5x…3x |
| Отладка | F3 — тики и время, F4 — пути и непроходимые клетки, F6 — +50 юнитов |

Все хоткеи переназначаются в `data/hotkeys.json`, числа баланса и движения лежат в `data/`.
