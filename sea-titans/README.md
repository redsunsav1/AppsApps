# Морские титаны

Личная фанатская подводная RTS по мотивам Submarine Titans в стиле 8-bit. ТЗ: [GAME_SPEC.md](GAME_SPEC.md), архитектура: [ARCHITECTURE.md](ARCHITECTURE.md).

## Цель партии

Добывай металл сборщиками, строй флот и уничтожь красный командный центр. Противником управляет ИИ: он строит экономику, защищает базу и посылает растущие волны атак.

## Запуск

```bash
cd sea-titans
npm install
npm run dev            # http://localhost:5180
npm test               # тесты логики (Vitest), включая партию ИИ против ИИ до победы
npm run build:single   # один файл dist/sea-titans.html — открывается двойным кликом
```

## Управление

| Действие | Клавиши |
|---|---|
| Выбор | ЛКМ, рамка; Shift добавляет; двойной клик выбирает всех такого типа |
| ПКМ | по месту — плыть; по врагу — атаковать; по кристаллам (сборщики) — добывать; с выбранной базой — точка сбора |
| Строить | Q сборщик, E Скат, R Охотник, T Крейсер (база не обязана быть выбрана); ПКМ по кнопке отменяет заказ |
| Команды | F атака-движение, P патруль, X стоп, H держать позицию; Shift — в очередь |
| Группы | Ctrl+1..9 назначить, 1..9 выбрать, двойное нажатие — камера к группе |
| Камера | WASD, стрелки, края экрана, СКМ тащить, клик по миникарте, Home — к базе |
| Прочее | Пробел — пауза, +/− — скорость, M — звук, F1 — справка, F3 — отладка |

Все параметры (цены, урон, бонусы ролей, скорость, ИИ, палитра, хоткеи, пилоты и их реплики) лежат в `data/` и `assets/manifest.json`.
